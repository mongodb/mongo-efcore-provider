UseAnalyzer(string)

Configures the name of the analyzer to use by default for this index. This must be the name of a built-in analyzer (but consider using UseAnalyzer(BuiltInSearchAnalyzer) instead) or a custom analyzer defined in this index with AddCustomAnalyzer(string).

public SearchIndexBuilder UseAnalyzer(string analyzerName)
