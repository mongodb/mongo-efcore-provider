Methods

AddHtmlStripFilter(IEnumerable<string>?)

Adds the "htmlStrip" character filter to the custom analyzer being defined. This filter strips out HTML constructs.

AddIcuNormalizeFilter()

Adds the "icuNormalize" character filter to the custom analyzer being defined. This filter normalizes text with the ICU Normalizer. It is based on Lucene's "ICUNormalizer2CharFilter".

AddMappingFilter(IEnumerable<(string Original, string Replacement)>)

Adds the "mapping" character filter to the custom analyzer being defined. This filter applies user-specified normalization mappings to characters. It is based on Lucene's "MappingCharFilter". A mapping indicates that one character or group of characters should be substituted for another

AddPersianFilter()

Adds the "persian" character filter to the custom analyzer being defined. This filter replaces instances of zero-width non-joiner with the space character. This character filter is based on Lucene's "PersianCharFilter".
