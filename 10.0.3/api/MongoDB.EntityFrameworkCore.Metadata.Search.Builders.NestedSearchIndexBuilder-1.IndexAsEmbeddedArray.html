IndexAsEmbeddedArray<TMember>(string)

Indexes the given member as an embedded (nested) array of documents. Further indexing can then be configured on members of this documents in the embedded array.

public NestedSearchIndexBuilder<TMember> IndexAsEmbeddedArray<TMember>(string memberName)

Parameters

memberName string

The name of the field or property to index.

Returns

NestedSearchIndexBuilder<TMember>

A NestedSearchIndexBuilder<TEntity> to configure members of the embedded documents.

Type Parameters

TMember

The CLR type of the embedded documents in the array.

Remarks

For more information about indexing embedded (nested) arrays of documents, see https://www.mongodb.com/docs/atlas/atlas-search/field-types/embedded-documents-type/.
