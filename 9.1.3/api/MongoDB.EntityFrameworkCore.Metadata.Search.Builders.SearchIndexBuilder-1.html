IsDynamic(bool)

Configures this index as "dynamic", meaning that all properties will be indexed automatically using the default search index type set. When dynamic, properties are indexed as boolean, date, 32 and 64-bit integer, double precision floating point number, objectID, string, or UUID.

IsDynamicWithTypeSet(string)

Configures this index as "dynamic", meaning that all properties will be indexed automatically using the type set with the given name. The type set must be defined and added to the index using AddTypeSet(string, Action<TypeSetSearchIndexBuilder>).

StoreAllSource(bool)

Configures storing all indexed fields in the document. Note that storing full documents might significantly impact performance during indexing and querying. Consider only storing some fields using StoreSourceFor(string, bool).

StoreSourceFor(string, bool)

Configures storing or excluding source for the given field or property.
